# Auto Diagnostic Knowledge Base

Car fault knowledge base on ArangoDB: OBD-II codes, symptoms, causes, components, solutions and service history in one graph. NoSQL Databases course project.

Stack: Python, FastAPI, ArangoDB 3.11, Streamlit, Docker Compose.

## Documentation

    python3 -m venv .venv && source .venv/bin/activate
    pip install mkdocs pymdown-extensions
    mkdocs serve
