# Code lookup

- Search box at the top. If the input looks like a code (`P0420`), it opens that code; otherwise it runs full-text search.
- Filters for the list view: category (P, B, C, U), minimum severity.
- Paginated table: code, description, system, severity.
- Code detail:
    - header with code, description, severity badge, category, system, generic or manufacturer specific
    - diagnosis tree as in Diagnose
    - list of symptoms with their weight
    - engines where this code is a known issue, with frequency
    - graph view button
- Search results show the type (symptom, code, cause, component) next to each hit.
