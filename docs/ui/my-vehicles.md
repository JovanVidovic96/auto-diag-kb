# My vehicles

**Owner view**

- Cards for each owned vehicle: maker and model, year, plate, mileage, date of last service.
- Button "Add vehicle" opens a form: VIN, plate, year, mileage, color, maker, model, engine (engine list filtered by model).
- Clicking a card opens Vehicle detail.

**Mechanic and admin view (search mode)**

- Search box for VIN or plate.
- Results table: VIN, plate, model, engine, current owner, last service.
- Admin also gets "Add vehicle" with an extra owner field.
