# Catalog

Drill-down in three levels.

- Maker select at the top.
- Models of the maker as cards: name, generation, years, body type.
- Selecting a model shows its engines in a table: code, fuel, displacement, power, years in this model.
- Selecting an engine shows:
    - components grouped by system
    - known issues table: code, frequency, severity, note
    - for each component, a link "What can go wrong" (codes the part can cause)
- Separate expander "Find a connection": two pickers (from, to) and a button that shows the shortest path as a small chain of boxes.
