# Vehicle detail

- Header: maker, model, generation, year, VIN, plate, mileage, engine code and power, current owner (hidden for other owners, who cannot open the page anyway).
- Box "Common problems for this engine": codes with frequency and severity.
- Service history as a timeline, newest first. Each entry: date, mileage, workshop, mechanic, total in RSD, codes as small badges, expandable list of replaced parts with brand, quantity and price, notes.
- Buttons:
    - mechanic: "New service record"
    - mechanic on own records and admin on all: edit and delete per entry
    - owner and admin: "Transfer vehicle" (asks for the new owner's username and a confirmation)
