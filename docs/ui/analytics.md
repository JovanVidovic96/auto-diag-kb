# Analytics

Tabs, one per report. Each tab has its filters at the top, a Plotly chart and the data table under it.

| Tab | Filters | Chart |
| --- | --- | --- |
| Top codes per model | model (optional) | horizontal bars per code, grouped by model |
| Spending per year | year range | bars for total, line for average |
| Faults by mileage | band size (25k, 50k, 100k km) | bars per band |
| Replaced parts | limit | horizontal bars, count and money |
| Workshops | none | table with services, distinct vehicles, average cost, revenue |

A small caption under each chart names the query (Q13 to Q17).
