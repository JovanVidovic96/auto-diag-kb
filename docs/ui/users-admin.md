# Users and workshops

Two tabs.

**Users**

- Table: username, full name, email, role, workshop (for mechanics), active.
- Filters: role, active.
- Row actions: change role, assign workshop (mechanics only), deactivate or reactivate.
- The admin's own row has role and active controls disabled.

**Workshops**

- Table: name, city, address, number of mechanics, number of services.
- New and Edit form: name, city, address, latitude, longitude.
- Small map with all workshops (`st.map`).
